# IRisNote 项目架构与文件索引

本文档是当前源码的开发地图，用来回答以下问题：

- 一个文件夹负责哪一类代码？
- 一个页面的路由文件和真正的业务 Screen 分别在哪里？
- 每个业务由哪些文件组成？
- 修改某个组件时，还需要检查哪些依赖文件？

本文档以当前仓库源码为准。Todo、Excerpt 和 Settings 仍是占位模块，文档不会把尚未存在的 API、Store 或组件描述为已实现。

## 1. 架构分层

```text
src/app       Expo Router 路由层，只定义 URL、Layout、重定向和 Screen 转发
src/core      应用级基础设施，例如全局 Provider、主导航和系统返回行为
src/features  按业务领域组织页面、API、业务组件、Hook、类型和状态协调
src/shared    跨业务复用且不包含具体业务语义的基础能力
```

主要依赖方向：

```text
app ──────────────→ core / features / shared
core ─────────────→ features（全局编排时）/ shared
features ─────────→ core（导航等壳层能力）/ shared
shared ───────────→ 第三方库或 shared 内部文件
```

必须遵守的边界：

- `app` 中不实现表单、请求、缓存或业务状态。
- `core` 中不放只属于笔记、认证或头像等单一业务的代码。
- `features` 可以使用 `core` 和 `shared`，但业务之间应避免直接读取彼此内部文件。
- `shared` 不得反向依赖 `features`、`core` 或 `app`。
- 笔记分类只服务于笔记，因此位于 `features/notes/categories`，而不是顶层 `features/categories`。

## 3. 路由层：`src/app`

`src/app` 是 Expo Router 的文件系统路由目录。除 `_layout.tsx` 和重定向外，页面文件都应是薄包装：

```tsx
export { default } from "@/features/notes/screens/NotesScreen";
```

### 3.1 URL 与 Screen 对照

| URL | 路由文件 | 业务实现 | 当前状态 |
| --- | --- | --- | --- |
| `/` | `src/app/index.tsx` | 无 | 重定向到笔记 Tab |
| `/note` | `src/app/(tabs)/note/index.tsx` | `features/notes/screens/NotesScreen.tsx` | 已实现 |
| `/todo` | `src/app/(tabs)/todo/index.tsx` | `features/todos/screens/TodosScreen.tsx` | 占位 |
| `/excerpt` | `src/app/(tabs)/excerpt/index.tsx` | `features/excerpts/screens/ExcerptsScreen.tsx` | 占位 |
| `/user` | `src/app/(tabs)/user/index.tsx` | `features/profile/screens/ProfileScreen.tsx` | 已实现主要流程 |
| `/auth/login` | `src/app/auth/login.tsx` | `features/auth/screens/LoginScreen.tsx` | 已实现 |
| `/auth/register` | `src/app/auth/register.tsx` | `features/auth/screens/RegisterScreen.tsx` | 已实现 |
| `/pages/note/create` | `src/app/pages/note/create.tsx` | `features/notes/screens/CreateNoteScreen.tsx` | 已实现 |
| `/pages/note/:id` | `src/app/pages/note/[id].tsx` | `features/notes/screens/NoteDetailScreen.tsx` | 已实现 |
| `/pages/todo/create` | `src/app/pages/todo/create.tsx` | `features/todos/screens/CreateTodoScreen.tsx` | 占位 |

`(tabs)` 是路由组，不出现在 URL 中；`pages` 是普通目录，会真实出现在 URL 中。

## 4. 应用基础设施：`src/core`

### 4.1 `core/providers`

| 文件 | 职责 | 使用方 |
| --- | --- | --- |
| `providers/AppProviders.tsx` | 聚合 `AuthProvider` 与 `GestureHandlerRootView`，向整个应用提供认证上下文和手势根容器。 | `app/_layout.tsx` |

### 4.2 `core/navigation`

| 文件 | 职责 | 主要使用方 |
| --- | --- | --- |
| `navigation.types.ts` | 定义 `TabKey` 和主操作 `MainAction` 类型。 | `navigation.constants.ts` |
| `navigation.constants.ts` | 主 Tab 唯一配置源；维护 Tab 顺序、菜单项、路径识别和各 Tab 的主操作路由。 | `FloatingMenu`、`FloatingActionButton`、`useSwipeTab` |
| `floating-menu-visibility.ts` | 内存事件总线；读取、设置和订阅浮动菜单隐藏状态。 | `FloatingMenu`、`NotesScreen` |
| `components/FloatingMenu.tsx` | 自定义 Tab Bar；显示四个业务入口、激活动画、上下滑切换和主操作按钮。 | `app/(tabs)/_layout.tsx` |
| `components/FloatingActionButton.tsx` | 根据当前 Tab 打开新建笔记、待办、摘录或设置页面；支持点击、长按和摇晃动画。 | `FloatingMenu` |
| `components/TabsBackExitHandler.tsx` | Android Tab 根页面双击返回退出；第一次返回显示 Toast，1500ms 内再次返回退出。 | `app/(tabs)/_layout.tsx` |
| `hooks/useDebouncedNavigation.ts` | 导航防重复；序列化目标作为锁键，延迟执行并在解锁前阻止重复跳转。 | 主操作按钮、笔记列表、分类栏 |
| `hooks/useLongPressNavigation.ts` | 400ms 长按手势、缩放动画和单次导航。 | 主操作按钮、分类栏头像 |
| `hooks/useSwipeTab.ts` | 在浮动菜单区域识别纵向手势，并按 Tab 顺序循环切换。 | `FloatingMenu` |

新增 Tab 时需要同步修改：

- `navigation.types.ts` 的 `TabKey`。
- `navigation.constants.ts` 的顺序、索引、菜单项、路径识别和主操作。
- `app/(tabs)/_layout.tsx` 的 `Tabs.Screen`。
- 新 Tab 对应的 `app/(tabs)/<name>` 路由目录和 Feature Screen。

## 5. 跨业务共享层：`src/shared`

### 5.1 HTTP 与错误处理

| 文件 | 职责 | 使用方 |
| --- | --- | --- |
| `http/client.ts` | Axios 单例；读取 `EXPO_PUBLIC_BASE_URL`，自动附加 Bearer Token，并为验证码、注册和登录请求附加持久化设备 ID。 | Auth、Notes、Categories、Profile API |
| `http/errors.ts` | 从 Axios 错误中提取服务端 `error`、`message`、重试秒数和剩余次数，提供统一错误文案。 | Auth Screen、Notes Screen、笔记状态 Hook |

所有 Feature API 都应复用 `client.ts`，否则会丢失 Token 和设备 ID 处理。

### 5.2 本地存储

| 文件 | 职责 | 使用方 |
| --- | --- | --- |
| `storage/storage.keys.ts` | AsyncStorage 键名唯一来源：Token、用户资料和设备 ID。 | HTTP Client、AuthProvider、登录和注册页 |

### 5.3 通用 Hook 与类型

| 文件 | 职责 | 使用方 |
| --- | --- | --- |
| `hooks/useDebouncedAction.ts` | 按业务动作键分别加锁，默认 500ms 内阻止同一动作重复执行。 | `SwipeableNoteItem` |
| `types/user.ts` | Auth 与 Profile 共享的用户身份结构。 | `auth.types.ts`、会话 API、AuthProvider |

### 5.4 Theme

| 文件 | 职责 | 当前使用情况 |
| --- | --- | --- |
| `theme/colors.ts` | 图标、SVG、动画和动态对象样式使用的颜色 Token。 | 全项目广泛使用 |
| `theme/radius.ts` | 数值型圆角 Token。 | 分类栏头像等对象样式 |
| `theme/spacing.ts` | 数值型间距 Token。 | 已定义，当前业务尚未直接引用 |
| `theme/typography.ts` | 字号和字重 Token。 | 已定义，当前业务尚未直接引用 |
| `theme/motion.ts` | `buttonEasing`、`pulse`、`shake` 等 Reanimated 动画 Token。 | Core 导航、分类按钮 |
| `theme/index.ts` | 导出颜色、圆角、间距和排版；动画当前从 `theme/motion` 直接引入。 | 全项目 |

静态布局和静态颜色主要使用 `global.css` 中的 NativeWind Token；图标 `color`、SVG `fill`、动画值和运行时对象样式使用 `shared/theme`。

### 5.5 Shared UI

| 文件 | 职责 | 主要使用方 |
| --- | --- | --- |
| `ui/Button/Button.tsx` | 基于 `Pressable` 的通用按钮，支持 `primary`、`disabled`、`secondary`、`danger` 外观；`variant="disabled"` 只改变样式，真正禁用还要传 `disabled` 属性。 | Auth、分类弹窗、详情状态页 |

| `ui/Card/Card.tsx` | 通用表面容器，支持 `surface` 和 `muted`。 | Profile |
| `ui/Card/index.ts` | 转发 Card 实现。 | `ui/index.ts` |
| `ui/ModalPanel/ModalPanel.tsx` | 统一弹窗面板，支持 `create`、`actions`、`confirm` 尺寸和样式。 | Categories |
| `ui/ModalPanel/index.ts` | 转发 ModalPanel 实现。 | `ui/index.ts` |
| `ui/Screen/Screen.tsx` | 页面根容器，支持 `plain`、`surface`、`centeredMuted`。 | Profile、Settings、Todos、Excerpts |
| `ui/Screen/index.ts` | 转发 Screen 实现。 | `ui/index.ts` |
| `ui/TextField/TextField.tsx` | 统一输入框外观并透传原生 TextInput 属性。 | Login、Register |
| `ui/TextField/index.ts` | 转发 TextField 实现。 | `ui/index.ts` |
| `ui/index.ts` | Shared UI 公共出口。业务优先从 `@/shared/ui` 引入。 | 所有 Feature |

| 文件 | 职责 | 使用方 |

## 8. 目录选择规则

| 要新增的内容 | 放置位置 |
| --- | --- |
| URL、Layout、Redirect | `src/app` |
| 全局 Provider、主导航、系统级交互 | `src/core` |
| 单一业务页面 | `src/features/<feature>/screens` |
| 单一业务组件 | `src/features/<feature>/components` |
| 单一业务请求 | `src/features/<feature>/api` |
| 单一业务 Hook | `src/features/<feature>/hooks` |
| 单一业务平台服务 | `src/features/<feature>/services` |
| 单一业务类型 | `src/features/<feature>/<feature>.types.ts` |
| 跨业务基础 UI | `src/shared/ui` |
| 跨业务纯工具 | `src/shared/utils` |
| HTTP Client、错误标准化 | `src/shared/http` |
| AsyncStorage 键名 | `src/shared/storage` |
| 静态 NativeWind Token | `global.css` |
| 图标、SVG、动画对象 Token | `src/shared/theme` |
