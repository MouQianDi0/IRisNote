# IRisNote 编辑器阶段 1：本地数据库与迁移验证清单

> 适用版本：Expo SDK 56、`expo-sqlite ~56.0.5`
> 实现时间：2026-08-07 03:18:43 +08:00
> 当前状态：Android、iOS、Web 实现完成，验证后置
> 基础设施补修：2026-09-08 04:32:51 +08:00；事务外键、关闭顺序和并发迁移保护已补齐，新增诊断未执行

## 1. 本阶段范围

阶段 1 只建立跨平台本地数据库基础设施：

- 打开并初始化 `irisnote.db`。
- 使用 `PRAGMA user_version` 和 `schema_migrations` 管理结构版本。
- 为 Android、iOS 和 Web 提供同一公共数据库端口。
- 串行化公开查询和事务，防止事务期间插入无关查询。
- 提供重开持久化、迁移幂等、强制回滚和备份可读性诊断。

本阶段不创建草稿、Revision、Block、附件或同步业务表，也不改变 Notes 当前 API、缓存和保存语义。

## 2. 当前数据库结构

正式数据库：`irisnote.db`

阶段 1 引入的结构版本：1。当前项目已在阶段 2A 增加版本 2 的 `local_notes`；本次基础设施修复不新增迁移、不改变现有表或结构版本。

```sql
CREATE TABLE schema_migrations (
    version INTEGER PRIMARY KEY NOT NULL,
    name TEXT NOT NULL UNIQUE,
    applied_at TEXT NOT NULL
);
```

`PRAGMA user_version` 与表内迁移记录必须完全一致。数据库结构版本高于当前应用支持版本时，初始化必须安全停止，禁止降级覆盖。

## 3. 平台策略

### 3.1 Android 与 iOS

- 文件型数据库显式打开 `useNewConnection: true` 的独立事务连接，继承打开选项并保留原数据库目录。
- 在 `BEGIN IMMEDIATE` 前设置并读取确认 `foreign_keys = ON`，设置 5 秒忙等待；提交或回滚后关闭独立连接。
- 不再直接使用会先开始事务的 `withExclusiveTransactionAsync()`，避免事务内设置外键无效。
- 主连接初始化启用外键与 WAL；`:memory:` 特例复用受串行保护的主连接。

### 3.2 Web

- 复用主连接，在确认外键后执行 `BEGIN IMMEDIATE` / `COMMIT` / `ROLLBACK`。
- 公共数据库端口使用单一串行队列，事务运行期间不允许其他公共查询穿插。
- Metro 将 `wasm` 作为静态资源。
- 本地开发和 EAS Hosting 设置 COEP/COOP 响应头。
- 第三方托管必须自行设置相同响应头。

Expo SDK 56 的 Web SQLite 仍为 Alpha；实现完成不等于浏览器兼容性已经验收。

### 3.3 初始化、迁移与关闭

- 多个 Provider 共享同一初始化 Promise 和受控端口，以租约计数决定最后一次释放。
- 最后一次释放等待初始化结束，停止接收新任务，排空已接收任务后关闭一次；快速重挂载等待旧连接关闭，不发布旧租约端口。
- 初始化失败保留原始错误，不自动删除正式库；正常关闭失败阻断后续重开，避免复用状态不明的连接。
- 同一运行时按实际数据库路径串行初始化和迁移；每步迁移在 SQLite 写锁内重新读取版本及登记表，跳过已经提交的步骤。
- 跨标签页、多进程及 Web OPFS 锁竞争仍需实机验证；忙等待超时应报错，不等于自动重试或已经兼容所有并发环境。

## 4. 数据安全规则

1. 正式数据库初始化失败时不得自动删除、清空或重建文件。
2. 数据迁移必须在事务内完成，迁移记录和 `user_version` 与结构修改一同提交。
3. 用户或业务数据必须通过参数绑定传入。
4. 原始 SQLite 实例不得进入应用组件树，Feature 不得直接导入 `expo-sqlite`。
5. 开发诊断只允许删除以下两个固定临时库：
   - `irisnote-diagnostics.db`
   - `irisnote-diagnostics-backup.db`
6. 日志不得记录笔记正文、认证令牌或数据库二进制内容。

## 5. 开发诊断入口

只有开发构建显式设置以下变量时，应用初始化后才运行诊断：

```dotenv
EXPO_PUBLIC_DATABASE_DIAGNOSTICS=1
```

诊断依次检查：

1. 内存假资源检查共享初始化、引用计数、初始化中释放、幂等关闭、重开等待、初始化失败重试和关闭失败阻断。
2. 同一连接及同库不同连接并发初始化，核对迁移版本与登记表；重复执行迁移后版本不变。
3. 关闭并重新打开临时库后标记仍存在。
4. 通过公共端口强制事务回滚，确认写入记录不存在。
5. 在事务连接检查外键已开启、孤儿记录被拒绝、父记录删除后子记录级联删除。
6. 在事务和查询排队时请求关闭，确认新任务被拒绝、已接收任务完成、重复关闭幂等、重开后记录仍存在。
7. 备份数据库能够读取源数据库标记。
8. 最终关闭并删除两个固定临时库。

不得在生产环境开启该变量。
