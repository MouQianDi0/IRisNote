## 用户认证流程

```
┌─────────────────────────────────────────────────────────────────┐
│                        认证流程                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   注册                                                          │
│   ┌──────┐    POST /api/auth/register    ┌─────────┐            │
│   │ 客户端 ├─────────────────────────────►│ Express │            │
│   └──────┘   { email, password }          └────┬────┘            │
│                                                │                 │
│                                   bcrypt 加密密码 │                 │
│                                                ▼                 │
│                                          ┌──────────┐           │
│                                          │ PostgreSQL│           │
│                                          │ users 表 │           │
│                                          └──────────┘           │
│                                                │                 │
│                                   返回 JWT token │                 │
│   ┌──────┐   { token, user }                  │                 │
│   │ 客户端 │◄──────────────────────────────────┘                 │
│   └──┬───┘                                                      │
│      │ 存储 token 到 AsyncStorage                                │
│                                                                 │
│   登录                                                          │
│   ┌──────┐    POST /api/auth/login                            │
│   │ 客户端 ├─────────────────────────────► Express              │
│   └──────┘   { email, password }             │                  │
│                                   查用户 + bcrypt 比对         │
│                                              │                  │
│                                   返回 JWT + 用户信息            │
│   ┌──────┐                                  │                  │
│   │ 客户端 │◄────────────────────────────────┘                  │
│   └──┬───┘                                                      │
│      │                                                          │
│   后续请求                                                       │
│   ┌──────┐   GET /api/notes                                    │
│   │ 客户端 ├─────────────────────────────► authMiddleware       │
│   └──────┘   Authorization: Bearer xxx.yyy.zzz   │             │
│                                                   ▼             │
│                                        解析 JWT → 注入 userId    │
│                                                   │             │
│                                        SELECT * FROM notes      │
```

## 数据隔离原理

用户 A 永远看不到用户 B 的数据。关键点：

1. **后端从 JWT 解析 userId**，不依赖前端传参
2. **所有查询强加** **`WHERE user_id = $1`** 过滤
3. **用户不能伪造** — token 由服务端签发，签名验证

```typescript
// 中间件注入
function authMiddleware(req, res, next) {
    const token = req.headers.authorization?.split(" ")[1];
    const decoded = jwt.verify(token, SECRET_KEY);
    req.userId = decoded.userId;        // ← 从 JWT 解析，前端伪造不了
    next();
}

// 路由查询自动过滤
router.get("/notes", authMiddleware, async (req, res) => {
    const result = await pool.query(
        "SELECT * FROM notes WHERE user_id = $1",  // ← 强制过滤
        [req.userId]
    );
    res.json(result.rows);
});
```

## 完整建表 SQL

```sql
-- ========== 用户表 ==========
CREATE TABLE IF NOT EXISTS users (
    id            SERIAL PRIMARY KEY,
    email         VARCHAR(255) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    nickname      VARCHAR(50),
    avatar        TEXT,
    created_at    TIMESTAMP DEFAULT NOW()
);

-- ========== 分类表（带 user_id） ==========
CREATE TABLE IF NOT EXISTS categories (
    id          SERIAL PRIMARY KEY,
    user_id     INTEGER      NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    name        VARCHAR(50)  NOT NULL,
    icon        VARCHAR(50)  NOT NULL DEFAULT 'Folder',
    created_at  TIMESTAMP    DEFAULT NOW()
);

-- ========== 笔记表（补 user_id 等字段） ==========
ALTER TABLE notes
    ADD COLUMN IF NOT EXISTS user_id      INTEGER REFERENCES users(id) ON DELETE CASCADE,
    ADD COLUMN IF NOT EXISTS category_id  INTEGER REFERENCES categories(id),
    ADD COLUMN IF NOT EXISTS is_pinned    BOOLEAN DEFAULT false,
    ADD COLUMN IF NOT EXISTS color        VARCHAR(20) DEFAULT '#FFFFFF',
    ADD COLUMN IF NOT EXISTS updated_at   TIMESTAMP DEFAULT NOW();

-- ========== 待办表 ==========
CREATE TABLE IF NOT EXISTS todos (
    id           SERIAL PRIMARY KEY,
    user_id      INTEGER      NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    category_id  INTEGER      REFERENCES categories(id),
    title        VARCHAR(200) NOT NULL,
    is_completed BOOLEAN      DEFAULT false,
    due_date     DATE,
    priority     VARCHAR(10)  DEFAULT 'medium',   -- low / medium / high
    created_at   TIMESTAMP    DEFAULT NOW(),
    updated_at   TIMESTAMP    DEFAULT NOW()
);

-- ========== 摘录表 ==========
CREATE TABLE IF NOT EXISTS excerpts (
    id          SERIAL PRIMARY KEY,
    user_id     INTEGER      NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    category_id INTEGER      REFERENCES categories(id),
    title       VARCHAR(200) NOT NULL,
    content     TEXT,
    source_url  TEXT,
    color       VARCHAR(20)  DEFAULT '#FFFFFF',
    created_at  TIMESTAMP    DEFAULT NOW(),
    updated_at  TIMESTAMP    DEFAULT NOW()
);

-- ========== 预设分类（注册时通过 API 创建，不在此处硬编码） ==========
```

## 前端存储

客户端登录成功后，JWT token 存入 `AsyncStorage`：

```
AsyncStorage.setItem("token", response.token)
AsyncStorage.setItem("user", JSON.stringify(response.user))
```

后续每次请求通过 axios 拦截器自动附加：

```typescript
api.interceptors.request.use((config) => {
    const token = await AsyncStorage.getItem("token");
    if (token) {
        config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
});
```
