# 笔记查看进度组件

> 状态：本地阅读位置、快速滚动条、坐标气泡及导航面板已实现；2026-09-12 调整指示条高度 50px、气泡松手 1 秒隐藏、气泡最大宽 200px（两行截断）与锚点 (x−50, y−100)，待设备验收。
> 云端：用户已确认暂时没有后端接口；本次保存待同步记录并定义接口契约，实际云端同步、网络恢复补传及多端联调尚未实现。
> 标题／书签：已提供显式数据接入与跳转能力；当前正文没有结构化数据来源，实际查看器显示大纲空状态，不推断普通正文标题。

## 1. 目标与范围

为笔记查看器提供快速滚动、当前位置提示、段落标题与书签跳转，以及本地、云端阅读位置保存和恢复。

包含三个组件：

| 组件 | 职责 |
| --- | --- |
| 快速滚动条 | 指示阅读位置，按住拖动快速上下滚动 |
| 通用进度气泡 | 跟随手指显示位置，点击打开导航面板 |
| 阅读导航面板 | 展示段落标题和书签，点击跳转 |

**阅读位置保存与恢复为核心能力，优先于视觉增强。**

实施前基线：查看器仅在离开页面时保存本地整数百分比，没有行号恢复和云端同步；正文为纯文本。现已接入结构化本地阅读记录、原生／Web 正文测量和导航数据接口，云端接口仍待提供。相关代码为 `src/features/notes/components/viewer/NoteViewer.tsx`、`src/features/notes/components/viewer/NoteViewerContent.tsx` 和 `src/features/notes/data/note-reading-progress.ts`。

## 2. 滚动条 UI

- 位于正文滚动区域右侧，不进入顶部标题栏。
- 指示条宽 **10px**、高 **50px**，圆角矩形。
- 内部使用 `move-vertical` 图标。
- 指示条位置随阅读进度变化；拖至顶部、底部分别对应正文起点、终点。
- 正常滚动时显示，停止交互 **5 秒**后隐藏。

原生实现建议将上述尺寸对应为逻辑单位 dp，避免不同像素密度下尺寸不一致。

建议补充尺寸：

| 项目 | 建议值 |
| --- | --- |
| 指示条圆角 | 5dp |
| 距正文容器右边缘 | 4dp |
| 图标尺寸 | 8dp，保持比例 |
| 透明触摸区域 | 宽 44 × 高 50dp（覆盖视觉指示条） |
| 轨道上下留白 | 8dp，并避开底部工具栏 |

可见指示条保持指定尺寸，扩大透明触摸区域以便按住。

## 3. 快速拖动 UX

1. 用户滑动正文，显示指示条。
2. 用户按住指示条，即进入快速拖动状态，同时显示进度气泡。
3. 手指上下移动，正文同步滚动；拖动开始时保留手指与指示条的相对位置，避免正文突然跳动。
4. 到达轨道边界后限制在顶部或底部。
5. 松开后保留当前阅读位置；气泡从松手时刻立即开始计时，**1 秒**后消失；指示条继续显示 5 秒。

拖动期间不触发正文选字或底层页面的其他点击。正文不足一屏时禁用快速拖动，进度显示 `100.00%`。

## 4. 通用进度气泡

### 位置

以手指在当前窗口中的坐标 `(x, y)` 为基准：

```text
气泡生成锚点 = (x - 50dp, y - 100dp)
```

此偏移定位的是气泡锚点（外框右下角，位于手指左上方：横向 50dp、纵向 100dp）；气泡外框应自动避让手指，并限制在屏幕安全区域内。接近边缘时允许调整位置，避免内容被裁切。

建议气泡内边距：水平 **12dp**、垂直 **8dp**；距安全区域边缘至少 **8dp**。气泡宽度随内容自适应，上限 **200px**（窄屏取容器宽 −16dp）；标题与书签文字最多 **两行**，超出宽度换行、两行截断。

### 内容

- 有当前段落标题：显示标题。
- 当前定位位置包含书签：显示书签标志；有书签名称时一并显示。
- 标题和书签同时存在：同时展示。
- 两者都没有：显示当前进度，保留两位小数，例如 `36.28%`。

“当前段落标题”按阅读位置所在章节确定；书签按所在段落或明确锚点匹配，不能仅凭附近存在书签就显示为已命中。

气泡外观（白底、圆角 14、边框、阴影）与宽度上限的完整视觉规格统一记录在 [IRisNote视觉设计规范](./IRisNote视觉设计规范.md) 的「阅读进度气泡」小节；本文档维护交互与数据规则。

### 生命周期

- 普通正文滚动仅显示滚动条；按住滚动条后显示气泡。
- 按住、拖动、点击气泡期间不自动隐藏。
- 松手时刻立即开始计时：气泡 **1 秒**后消失；期间正文滚动不重置该计时，仅再次按住滚动条或气泡会重置。
- 指示条本体不受 1 秒规则影响，停止交互 **5 秒**后隐藏。
- 隐藏后不保留透明触摸层，避免拦截正文操作。
- 打开导航面板后，结束拖动并隐藏气泡；面板不受上述隐藏倒计时影响。

现有 `AnchoredPopover` 采用视图锚点和 Modal。跟随手指的气泡需要评估坐标锚点和手势连续性，不能直接假定现有接口能够复用。相关说明见 [通用锚点气泡菜单使用与实现详解](./通用锚点气泡菜单使用与实现详解.md)。

## 5. 阅读导航面板

点击进度气泡，打开类似用户参考图 2 的底部面板。

```text
┌────────────────────────────┐
│           大纲          关闭 │
├────────────────────────────┤
│ 段落标题一                  │
│   子标题                    │
│   书签标志 书签名称          │
│ 段落标题二                  │
└────────────────────────────┘
```

建议布局：

- 顶部圆角 **16dp**，初始高度约为可用区域的 **60%**。
- 标题栏高 **48dp**，标题水平居中，关闭按钮位于右侧。
- 内容水平内边距 **16dp**。
- 条目最小高度 **44dp**；子标题每级缩进 **16dp**。
- 底部留出设备安全区。
- 白色面板、深色正文；当前定位条目使用主题色突出。

标题和书签按正文顺序排列，书签使用明确图标区分。点击条目后关闭面板，跳转至对应位置，并更新阅读进度。

没有段落标题和书签时显示“暂无段落标题或书签”，不自动把普通正文猜测为标题。

本模块消费已有或后续建立的标题、书签数据；书签新增、编辑和删除入口不纳入本次范围。

## 6. 阅读位置与行号

**不能只保存百分比，也不能只保存滚动像素。**

建议定义：

- 行号从 **1** 开始，以正文换行分隔的逻辑行为准。
- 屏幕自动折行不增加逻辑行号。
- 保存顶部可见正文对应的逻辑行号，并附带行内字符偏移。
- 百分比用于显示、兼容旧数据及定位失败时的回退。

推荐保存字段：

| 字段 | 用途 |
| --- | --- |
| 用户标识 | 隔离不同账户 |
| 本地笔记标识／服务端标识 | 关联同一篇笔记 |
| 内容版本 | 判断保存位置是否仍适用 |
| 逻辑行号 | “滚动到 xx 行”的主要定位依据 |
| 行内字符偏移 | 定位较长的逻辑行 |
| 段落或文本锚点 | 内容编辑后辅助重定位 |
| 百分比 | 显示及回退 |
| 更新时间、同步版本 | 处理保存顺序和多端冲突 |

空正文保存起始位置；不把标题、分类、日期等元信息计入正文行号。

## 7. 本地保存与云端同步

- 阅读位置先保存本地，再异步同步云端。
- 滚动期间合并高频更新，不能逐帧写数据库或发请求。
- 拖动结束、导航跳转、页面失焦、应用进入后台时，尽力立即落盘。
- 建议普通滚动采用最长 1 秒间隔的节流保存，降低意外退出造成的位置丢失。
- 离线时保留最新待同步位置，网络恢复后补传。
- 阅读位置作为独立元数据保存，不创建笔记正文新版本。
- 本地未同步笔记可保存进度；获得服务端标识后再同步，禁止将本地负数 ID 用作云端请求 ID。
- 账户切换、笔记切换后，旧异步任务不得覆盖新会话。

多端进度不能采用“百分比取最大值”，因为用户可能主动回看。建议使用服务端版本校验及冲突处理，避免旧设备延迟上传覆盖较新的阅读位置；具体接口仍需设计。

保存失败应保留最新待保存位置并提供可重试机制，不能误报为已同步。

## 8. 查看器恢复流程

1. 打开笔记，读取本地阅读记录。
2. 等正文和布局就绪后，按行号及字符偏移恢复。
3. 异步读取云端记录并比较版本。
4. 用户已开始滚动、拖动或跳转后，禁止用迟到的云端结果强制改变当前位置。
5. 程序恢复期间暂停记录中间位置，防止初始 `0%` 覆盖历史记录。

正文变化后的定位优先级：

```text
有效文本／段落锚点
→ 对应逻辑行号及字符偏移
→ 百分比回退
→ 正文起点
```

旧版整数百分比记录继续兼容，首次成功定位后升级为新结构。字体大小和屏幕宽度变化后重新计算布局，以正文锚点恢复。

## 10. 风险与验收标准

最不确定的事项是：纯文本正文如何获得可靠的标题结构，以及逻辑行、字符位置在不同设备上的准确定位。现有单个 `Text` 渲染方式需要先验证测量能力。

容易遗漏的情况包括：

- 正文前面插入或删除内容后，历史行号发生变化。
- 同一逻辑行很长，跨越多个屏幕。
- 气泡在用户松手后仍可点击。
- 原生手势与正文选字、底部工具栏发生冲突。
- 多端离线阅读后同步顺序与实际阅读顺序不同。

验收覆盖：

- 指示条尺寸、图标、边界和快速拖动。
- 气泡锚点（横向 50dp、纵向 100dp）、屏幕边缘避让、两位小数进度与两行截断。
- 停止交互后指示条 5 秒隐藏、气泡松手 1 秒隐藏；持续交互期间保持可见。
- 标题与书签跳转准确。
- 退出重开后恢复到保存行号附近的正确正文位置。
- 本地、云端、离线补传及账户隔离。
- 正文变化、字体变化、横竖屏变化和短笔记。
- 旧百分比记录迁移，迟到的恢复结果不覆盖用户操作。

代码检查与设备交互验收分别记录，设备验收由用户主动发起。

### 11.2 本地记录

- 沿用 `irisnote:reading:<ownerId>:<noteId>` 存储键；schema 2 保存 `ownerId`、`noteId`、`serverId`、`contentVersion`、`line`、`character`、`anchor`、`percent`、`updatedAt`、`localVersion`、`serverVersion`、`pendingSync`。
- 只将 CRLF／CR 归一化为 LF，不裁剪正文；行号从 1 开始，字符偏移使用 UTF-16 代码单元。标题和元信息不计入正文行号。
- 原生端根据 `Text.onTextLayout` 的视觉行映射原文；Web 端用 DOM Range 二分测量视觉行，避免逐字符扫描全部长正文。逻辑行可跨多个视觉行。
- 同一存储键串行执行写入；新会话读取会等待已排队的旧会话最终快照。写入失败时保留最新内存副本，后续保存、重新打开或点击重试可重新落盘；应用被强制终止时，尚未成功落盘的内存副本无法保证保留。
- 旧整数百分比在读取和布局成功后升级；损坏或账户不匹配的记录报错保留，不直接用 0 覆盖。现有笔记信息浮层的兼容读取函数仍返回整数展示值，结构化记录保留精度，进度气泡固定两位小数。
- 空正文保存第 1 行、第 0 字符和起始百分比；短正文气泡显示 `100.00%`，可按住查看气泡，但禁止拖动改变位置。
- 标题区域仍可见时，标题重排不自动跳过标题；正文重排则按已有文本位置恢复。位置不变时保留导航条目的精确字符锚点。

### 11.3 标题与书签数据

调用方通过 `NoteViewer` 的可选 `navigationEntries` 传入 `ReadingNavigationEntry[]`：

```ts
[
  { id: 'heading-1', kind: 'heading', title: '章节一', line: 1, level: 1 },
  { id: 'heading-2', kind: 'heading', title: '子章节', line: 12, level: 2 },
  { id: 'bookmark-1', kind: 'bookmark', title: '继续阅读', line: 20 },
  { id: 'bookmark-2', kind: 'bookmark', title: '定位片段', line: 30, character: 10, endCharacter: 24 },
]
```

`id` 必须唯一且稳定；行号对应当前原文。未指定 `character` 的书签匹配整条逻辑行，指定后按精确字符或显式闭区间匹配。标题按当前位置之前最近的标题确定；普通正文不自动生成条目。书签增删改入口仍不在本次范围。

### 11.4 云端未完成项

- `ReadingProgressTransport` 仅定义读取和携带 `expectedServerVersion`、幂等 `mutationId` 的写入接口，响应区分成功和版本冲突。
- `readingProgressStore.listPending(ownerId)` 可读取账户的待同步记录；当前 `pendingSync` 不会被自动清除，`READING_CLOUD_STATUS` 为 `unavailable`。
- 实际接口地址、鉴权、服务端版本生成、设备离线冲突策略、幂等实现、网络恢复触发器、已上传快照的条件确认，以及本地笔记获得服务端 ID 后的后台绑定仍需后端阶段接入。
- 已知正数服务端 ID 会写入记录；负数客户端 ID 不会成为云端 ID。未绑定记录继续保留，本地保存无需等待后端。
- 云端阶段禁止按百分比取最大值；已发生用户交互或存在本地待同步记录时，禁止用迟到的云端读取结果强制恢复位置。
