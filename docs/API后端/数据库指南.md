# 前端如何从数据库拉取数据 & 上传数据（完整指南）

## 一、整体架构

前端（React Native / Web） │ │ HTTP请求（fetch / axios） ▼ 后端（Node.js
/ SpringBoot / Go） │ │ SQL / ORM ▼ 数据库（MySQL / PostgreSQL /
MongoDB）

> 前端不能直接访问数据库，必须通过后端API。

------------------------------------------------------------------------

## 二、从数据库获取数据（GET）

### 后端接口

GET /api/notes

``` javascript
app.get("/api/notes", async (req, res) => {
    const notes = await db.query("SELECT * FROM notes");
    res.json(notes);
});
```

返回数据：

``` json
[
  { "id": 1, "title": "第一篇笔记", "content": "hello" },
  { "id": 2, "title": "学习React", "content": "React Native" }
]
```

------------------------------------------------------------------------

### 前端请求

#### fetch方式

``` javascript
useEffect(() => {
    fetch("https://api.example.com/api/notes")
        .then(res => res.json())
        .then(data => console.log(data));
}, []);
```

#### axios方式

``` javascript
import axios from "axios";

useEffect(() => {
    axios.get("https://api.example.com/api/notes")
        .then(res => setNotes(res.data));
}, []);
```

#### 渲染列表

``` javascript
<FlatList
    data={notes}
    renderItem={({ item }) => (
        <Text>{item.title}</Text>
    )}
/>
```

## 三、上传数据（POST）

### 前端发送

``` javascript
axios.post("/api/notes", {
    title: "React Native",
    content: "今天学习了动画"
});
```

------------------------------------------------------------------------

### 后端接收

``` javascript
app.post("/api/notes", async (req, res) => {
    const { title, content } = req.body;

    await db.query(
        "INSERT INTO notes(title, content) VALUES (?, ?)",
        [title, content]
    );

    res.json({ success: true });
});
```

------------------------------------------------------------------------

## 四、更新数据（PUT）

### 前端

``` javascript
axios.put("/api/notes/3", {
    title: "新标题",
    content: "新内容"
});
```

### 后端

``` javascript
app.put("/api/notes/:id", async (req, res) => {
    const { id } = req.params;
    const { title, content } = req.body;

    await db.query(
        "UPDATE notes SET title=?, content=? WHERE id=?",
        [title, content, id]
    );

    res.json({ success: true });
});
```

------------------------------------------------------------------------

## 五、删除数据（DELETE）

### 前端

``` javascript
axios.delete("/api/notes/3");
```

### 后端

``` javascript
app.delete("/api/notes/:id", async (req, res) => {
    const { id } = req.params;

    await db.query(
        "DELETE FROM notes WHERE id=?",
        [id]
    );

    res.json({ success: true });
});
```
