# 第三方数据许可

IRisNote 随应用分发的第三方数据及其许可。本文件记录数据来源、许可义务与在应用内的署名位置；新增或更新第三方数据时同步维护。

## 地区数据

| 项目 | 说明 |
| --- | --- |
| 数据文件 | `src/features/profile/data/regions.json` |
| 生成方式 | `node scripts/build-region-dictionary.mjs`（固定发布版并校验 SHA-256） |
| 来源 | [Countries States Cities Database](https://github.com/dr5hn/countries-states-cities-database)，发布版 `v3.2-export.7` |
| 许可 | [Open Database License (ODbL) v1.0](https://opendatacommons.org/licenses/odbl/1-0/) |
| 署名 | Data by Countries States Cities Database \| https://github.com/dr5hn/countries-states-cities-database \| ODbL v1.0 |
| 应用内署名位置 | 设置 → 关于 IRisNote →「数据来源」 |
| 派生数据库 | `regions.json` 为筛选与修订后的派生数据库，同样以 ODbL v1.0 提供，声明见同目录 `REGIONS-LICENSE.md` |

许可义务：

1. 在应用内公开使用处保留署名（关于页「数据来源」）。
2. 派生数据库（`regions.json`）以 ODbL v1.0 提供，并随公开仓库可获取。
3. ODbL 仅约束该数据文件，不改变 IRisNote 其他源代码的许可。

修订说明：台湾、香港、澳门不作为第一级，归入中国省级并显示为中国台湾、中国香港、中国澳门；修正部分错误或过时译名并区分同名条目，全部修订记录在生成脚本的 `NAME_OVERRIDES` 中。
