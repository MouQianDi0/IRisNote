## 1. 目标与完成边界

本文中的“公共化插件”统一按“可复用公共 UI 组件及其主题能力”理解。

最终目标：页面只传入文案、数据、业务回调和 `variant`、`size`、`state` 等语义属性；颜色、形状、间距、状态优先级、加载反馈和无障碍统一由主题与公共组件负责。

全部完成必须同时满足：

- [ ] 主题颜色可以通过一个主题预设集中修改，不需要逐页替换色值。
- [ ] 公共组件不直接使用未命名的颜色、圆角、字号和重复间距。
- [ ] 确认、取消、危险、禁用、加载等状态在所有弹窗和页面中一致。
- [ ] 普通按钮、有底图标按钮、图标选择单元、阅读进度气泡的圆角均为 `16dp`。
- [ ] 输入框使用独立的 `16dp` 字段圆角，不再借用卡片圆角。
- [ ] 已列出的旧组件和页面临时实现完成迁移，不留下两套并行入口。
- [ ] 公共组件具备必要的无障碍名称、状态和最小触控范围。
- [ ] 静态检查通过；浏览器和真机交互验收由用户主动发起并完成。

## 2. 当前问题与证据

### 2.1 重复实现

- 按钮至少存在三套：`src/shared/ui/Button`、`AuthButton`、编辑器 `DialogButton`。
- 输入框已有 `src/shared/ui/TextField`，但认证页仍使用 `AuthField`，其他页面仍直接组合 `TextInput`。
- 返回入口在认证布局、笔记阅读页和编辑器内分别实现，尺寸、组件类型和交互收口位置不统一。
- 图标选择器位于分类业务目录，桌面与移动布局分别维护相似的图标选择单元。
- 弹窗内容已复用 `AppModal`，但标题、关闭按钮、内容间距和底部按钮区仍由业务组件重复拼装。
- 加载、空状态、错误提示、列表选择行等常见结构尚无统一公共组件。

### 2.2 主题与 Token 漂移

- 当前视觉值同时存在于 `global.css` 和 `src/shared/theme`，手动改主题时可能漏改其中一侧。
- `colors.ts` 仍混合基础语义色、业务专用色和组件状态色，无法安全整套换肤。
- `radii.control`、`radii.card`、`radii.hyperControl` 的职责重叠。
- `hyperControl` 同时被按钮、图标选择单元、分类状态按钮、笔记菜单和编辑器浮动工具栏使用，不能直接全局替换而不审查调用方。
- 部分组件仍存在 `borderRadius: 14`、固定十六进制颜色和任意值类名。

### 2.3 已确认的设计决定

- 危险按钮禁用背景：`#F8D7D2`。
- 危险按钮禁用文字和图标：`#E94634`。
- 普通按钮圆角：`16dp`。
- 有底图标按钮圆角：`16dp`。
- 图标选择单元圆角：`16dp`。
- 阅读进度气泡圆角：`16dp`。
- 输入框圆角：独立使用 `radii.field = 16dp`。
- 页面不得通过任意颜色属性覆盖公共组件的身份色；新增视觉语义必须先进入主题。

## 13. 实施批次建议

为降低回归和审查成本，建议按以下批次分别实施并记录：

1. **主题与圆角基座**：ThemePreset、语义颜色、组件配方、CSS/原生映射、一致性检查。
2. **文字与按钮**：AppText、AppButton、IconButton、BackButton；先迁移认证域作为参考实现。
3. **输入框**：Input、FormField；迁移认证和分类创建。
4. **弹窗体系**：DialogActions、AppDialog；迁移分类弹窗和草稿弹窗。
5. **图标选择器**：IconPickerGrid、IconPickerDialog；收口桌面与移动布局。
6. **状态与列表**：AsyncStateView、InlineMessage、ListRow、SelectionRow。
7. **阅读与笔记迁移**：返回按钮、进度气泡、上下文菜单、阅读导航弹窗。
8. **清理与验收**：删除旧实现、复跑审计、同步文档、交由用户完成设备验收。

每一批只在上一批接口稳定后开始；发现新业务差异时优先扩展现有组件变体，不立即新增近似组件。

## 14. 风险与实施约束

- **主题双源风险**：在生成/映射机制落地前，CSS 与 TypeScript 值可能再次漂移。
- **圆角连带风险**：旧 `hyperControl` 曾同时影响按钮与编辑器工具栏；现已拆出 `editorToolbar = 16dp`，后续仍禁止跨组件复用身份圆角。
- **输入行为风险**：普通字段可公共化，但笔记编辑器不能因外观相似而迁移。
- **弹窗层级风险**：不能用普通 `zIndex` 替换当前 `AppModal`/Overlay 方案。
- **大字体风险**：固定高度和横排按钮可能在无障碍字体下溢出，应使用最小高度和可重排布局。
- **迁移中断风险**：兼容层必须标记删除条件，避免长期保留新旧两套系统。
- **主题接口膨胀风险**：页面出现一次性颜色需求时不能立即扩充公共 API，应先判断是否为业务配方。
