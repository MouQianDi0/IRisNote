## 3. 数据和调用逻辑

1. `useTodoScope` 等待鉴权加载结束，确定 `user:<id>` 或本次进程的 `guest:<uuid>` 所有者，再激活仓库。所有者不匹配期间不呈现旧数据。
2. 仓库拥有实体事实；激活不同所有者会清空 Map、增加代次并广播。store 订阅仓库，保存实体快照与当前选中日期；作用域切换时清空选中日期。
3. 列表按选中日期查询；没有选中日期时使用统一时钟的今天。浏览日历周窗口和真正选中日期是不同操作，浏览周本身不修改列表查询日期。
4. 页面先按日期、状态、正文关键词过滤，再确定排序；卡片标题、时间摘要、状态和颜色是事实的投影，没有额外写回仓库。
5. 打开表单时固定初始日期、编辑基线和创建 ID。新建继承选中日期，否则取打开时的今天；跨午夜不自动改写已打开表单的日期。
6. 表单退出先根据退出原因判断丢弃或校验；有效保存经服务检查所有者与代次，再调用仓库命令。保存成功才关闭；失败保留字段并显示错误。
7. 仓库写入并广播后，store 更新快照，列表重新查询并渲染。批量操作先全部校验，再一起写入／删除，只广播一次。

### 3.1 新建／编辑退出矩阵

| 操作 | 新建表单 | 编辑表单 |
| --- | --- | --- |
| 确认创建／保存 | 校验成功写入，失败留在弹窗 | 校验成功合并修改字段，失败留在弹窗 |
| 取消 | 丢弃本次输入，不创建 | 丢弃本次输入，不更新原实体 |
| 点击遮罩／系统返回，正文为空白 | 直接关闭，不创建 | 空正文校验失败，留在弹窗，不删除实体 |
| 点击遮罩／系统返回，正文非空 | 校验成功自动保存并关闭，失败保留输入 | 同样校验并保存；失败保留输入 |
| 顶部删除图标 | 放弃创建，不执行仓库删除 | 打开两秒倒计时确认，再按当前捕获版本删除 |
| 日期／时间子弹窗取消或返回 | 关闭子弹窗，不触发父表单保存 | 同左 |

保存中锁定操作入口，使用同步 ref 锁防止重复保存。创建 ID 在表单会话内固定，同 ID 同内容重试返回原实体、不重复广播；不同内容拒绝覆盖。

### 3.2 校验和并发规则

- 正文不能全为空白，最多 4000 个 Unicode 码点；统一 CRLF／CR 为 LF，保留正文空格和段落。
- 日期是本地 `YYYY-MM-DD`，必须是真实公历日期；时间必须是 `HH:mm`，小时 00—23、分钟 00—59。
- 结束时间需要开始时间，不能早于开始时间；相等允许零时长，不能用结束时间表达跨日区间。清空开始时间时同时清空结束时间。
- 时区由设备获取，无法获取时为 null，不阻止保存；当前状态推导使用设备本地日期和时间，没有实现按实体时区跨区重算。
- 编辑仅提交白名单内相对基线改变的表单字段。其他操作改过完成状态时，保存正文保留最新完成事实；同一字段出现互斥修改时拒绝覆盖。
- 已删除记录不能由旧编辑表单重新创建；旧所有者／代次失效时拒绝提交。
- 无变化编辑及重复设置同一完成状态不增加版本或更新时间。完成写入 `completedAt`，取消完成清空该时间。

## 4. 状态、排序和批量操作

### 4.1 状态与五色是两套投影

状态按以下顺序判断：

1. 已完成优先，状态为 `completed`。
2. 未完成且所属日期早于今天，或今天的结束时间严格早于当前时刻，为 `expired`。
3. 未完成且所属日期晚于今天，或今天的开始时间严格晚于当前时刻，为 `pending`。
4. 其余为 `inProgress`。

开始恰好等于当前时刻即进入进行中；结束恰好等于当前时刻尚未过期，晚于该边界 1ms 才过期。全天和仅开始的待办在所属日期当天不会因缺少结束时间而提前过期，次日过期。

| 五色显示态 | 判断条件 |
| --- | --- |
| `low`／`normal`／`high` | 未完成，按优先级选择颜色，包括已过期但未完成的记录 |
| `done` | 已完成，所属日期是今天或未来日期 |
| `ended` | 已完成，所属日期早于今天，标题灰色并加删除线 |

只有“全部”筛选包含已完成记录；“待进行／进行中／已过期”按状态筛选未完成记录。统一时钟在开始、结束边界、午夜和最长一分钟兜底刷新；后台暂停，恢复前台和重新聚焦时刷新。领域边界测试通过，设备时钟生命周期尚待验收。

### 4.2 搜索与排序的准确顺序

1. 固定当前查询日期。
2. 过滤状态及正文关键词；关键词 trim 后进行不区分大小写的包含匹配，不跨日期搜索。
3. 置顶组先于非置顶组。
4. 每组内有开始时间先于全天记录。
5. 时间升序／降序按开始时间排序；优先级模式先按高→普通→低，再按开始时间升序。同样先遵循第 3、4 步。
6. 相同条件按创建时间升序，再按 UUID 升序，保证稳定且确定的次序。

### 4.3 批量步骤

1. 长按一张卡片进入批量模式并选中该项，完成按钮在批量模式禁用。
2. 选中集合独立于实体；“全选”只选当前可见查询结果。手动取消全部选择仍可留在批量模式，操作按钮禁用。
3. 标星／置顶判断所选项是否全部开启：全部开启则统一关闭，否则统一开启。
4. 删除确认捕获 `clientId + localVersion`，等待共享两秒倒计时后执行；不会绕过确认直接删除。
5. 命令执行前核对作用域；仓库校验所有目标存在、版本一致和字段有效后才一起应用。任一失败时不产生部分写入／删除。
6. 改日期、筛选、关键词或切换搜索清空选择并退出批量；排序改变保留仍可见选择。外部删除或状态变化会清除隐藏／消失的选项，外部变更使选择全部消失时退出；硬件返回优先退出批量模式。
