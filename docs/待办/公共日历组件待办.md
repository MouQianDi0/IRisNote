### 2.2 关键裁定（历史存档，防止反复）

| 事项 | 结论 |
| --- | --- |
| 技术路线 | 路线 B（flash-calendar）；路线 A（纯自绘）否决 |
| 选中/今日形状 | 整格 48×48 矩形圆角 16dp（`radii.control` 连续圆角），取代 v1.0 的 40dp 圆；今日 surfaceSelected 底蓝字 |
| 分隔线 | 仅表头行底一条 1dp，标题行下不画（用户裁定） |
| 周视图交互 | 左右分页翻周（边缘静默重建近似无限）；下滑展开/上滑收起（垂直位移 >14dp 判定，220ms 高度动画） |
| 挂载间距 | 待办页容器上边框下 12dp（`pt-3`） |
| 范围之外 | agenda 模式、日程标注点、农历/节假日显示默认不做（规范 §1），需求出现另行立项 |
