## 0. 真机布局实测验收（uiautomator 对账）

组件实现与契约的以下三个场景必须先做真机布局实测，再下结论：

- **截图判读**：判断截图中组件尺寸/间距是否合规，以实测数值为准，不凭目测；
- **提出修改要求**：需求须附实测数据（当前实际值 vs 规范值），不接受"看起来不对"式反馈；
- **验证改动**：改后在真机导出控件树核对 dp 值，配合截图交用户验收。

实测步骤（真机已连接 adb）：

```bash
node scripts/ui-dump-parse.mjs   # 一键导出+解析，输出每个元素的 px 与 dp（--serial 指定设备）
adb shell wm density             # 需手动换算时查密度（1dp = 密度/160 px）
```

判读规则：

- dump 坐标是 **px**，须除以 `密度/160` 换算 dp（例：476dpi → 1dp=2.975px）；
- 文本 bounds 是**文字边界不是触摸热区**（例：`min-h-11` 按钮热区 44dp，文字仅约 18dp）；
- 原生树经 RN 扁平化，**看不到组件名与 padding 来源**，定位原因必须回源码；
- 可交互性以 content-desc（对应 accessibilityLabel）与 clickable 计数交叉判断；
- clickable 节点数天然多于 RN 触摸组件数（TextInput 外层容器等也被标记），1:1 对不上属正常；
- **无真机/未连接 adb 时跳过本步骤**，结论退回静态检查与目测，不得编造实测数值。

## 1. 目标与边界

- 页面只提供文案、数据、业务回调以及 `variant`、`size`、`state` 等语义属性；形状、颜色、状态组合和无障碍由公共组件负责。
- 后期手动修改主题时，只修改中央主题预设；组件和页面不得逐一替换颜色。
- 本规范覆盖 `AppButton`、`IconButton`、`BackButton`、`Input`、`InputSave`、`InlineHint`、`FormField`、`IconPickerGrid`、`IconPickerDialog`、`AppDialog`、`DialogActions`，并规定后续状态与列表类组件的契约。
- 笔记正文编辑器、草稿生命周期、分类删除手势等业务状态机不进入公共 UI；它们只复用本规范的基础组件。
- 当前产品只有浅色主题。规范保留深色和运行时主题切换接口，但不编造未确认的深色值。

## 2. 主题架构

### 2.1 三层取色

```text
ThemePreset（唯一主题预设）
├─ palette：原始色值
├─ semanticColors：用途明确的语义颜色
└─ component recipes：组件状态到语义颜色的映射
        ↓
公共组件
        ↓
业务页面只选择 variant / state / size
```

1. `palette` 只保存原始颜色，不允许组件直接依赖。
2. `semanticColors` 描述用途，如品牌主色、控件表面、焦点边框和危险操作。
3. 组件配方只能引用语义 Token，不得出现十六进制、RGB 或页面私有颜色。

默认浅色主题以 `src/shared/theme/presets/default-light.json` 为唯一原始值来源：TypeScript 主题对象直接解析该预设，`global.css` 的托管区块由 `npm run theme:sync` 生成，并可用 `npm run theme:check` 检查漂移。旧 `colors` 与 `radius` 导出仅作迁移兼容，新公共组件使用 `semanticColors`、`componentRecipes` 和 `radii`。

### 2.4 主题修改规则

- 修改主色时同步检查 `brandPrimary`、`onBrandPrimary`、`surfaceSelected`、`borderFocused`、`borderSelected`、`primaryDisabled` 和 `primaryFaded`。
- 修改危险色时同步检查 `destructive`、`onDestructive`、`destructiveDisabled` 和 `onDestructiveDisabled`。
- 修改表面色时检查页面、弹窗、输入框、次要按钮、图标格和列表选中态，不能只替换白色。
- `pressed` 可以使用统一透明度反馈；`disabled` 禁止使用透明度模拟。
- 页面若需要新颜色语义，先扩展 `SemanticColors`，再增加组件变体；禁止通过 `className` 绕过主题。

## 3. 通用状态契约

| 状态 | 视觉与行为 |
| --- | --- |
| `default` | 正常展示并可交互 |
| `pressed` | 整体透明度使用 `theme.motion.pressedOpacity`，当前默认 `0.85`；释放、取消或移出后恢复 |
| `focused` | 输入类使用 `borderFocused`；不得改变组件外部尺寸 |
| `selected` | 选择类使用 `surfaceSelected`、`borderSelected` 和 `brandPrimary` |
| `loading` | 保留原尺寸，阻止重复操作，展示活动指示器并保留可访问名称 |
| `disabled` | 原生禁用，使用显式禁用背景和前景，不响应点击 |
| `invalid` | 输入边框和错误信息使用 `destructive`，并暴露无障碍错误状态 |
| `readOnly` | 内容可选择、可复制但不可编辑，不伪装成禁用 |
| `unavailable` | 尚未开放的功能必须声明不可用，不能挂空回调 |

统一优先级：

```text
disabled > loading > invalid > selected/focused > pressed > default
```

### 3.1 AppText

- 排版使用 `themeTypography`，颜色使用 `semanticColors`；不在组件内重复写字号、字重或固定颜色。
- 支持 `caption`、`helper`、`label`、`body`、`control`、`title` 六种排版变体，以及正文、辅助、禁用、品牌、危险和反色等语义色调。
- 默认保留系统字体缩放；当前按钮规范不设置固定行高，狭窄控件通过单行截断处理。
- 不开放 `style` 身份覆盖；`className` 只用于对齐、外边距等布局扩展。

```ts
type AppTextTone =
    | "primary"
    | "secondary"
    | "disabled"
    | "brand"
    | "primaryFaded"
    | "onBrand"
    | "onPrimaryDisabled"
    | "danger"
    | "onDanger"
    | "onDestructiveDisabled";

type AppTextProps = Omit<TextProps, "style"> & {
    variant?: "caption" | "helper" | "label" | "body" | "control" | "title";
    tone?: AppTextTone;
    className?: string;
};
```

## 4. AppButton

### 4.1 形状与排版

- `standard` 高 48dp；`compact` 高 44dp。
- 圆角使用 `radii.control`，当前 16dp，并应用 continuous curve。
- 左右内边距 16dp；前置内容与文字间距 8dp。
- 文字 17sp、Regular、单行截断、水平垂直居中。
- `loading` 保留按钮宽高；活动指示器与文字颜色跟随当前前景 Token。

### 4.2 变体状态

| 变体 | 默认背景 / 内容 | 禁用背景 / 内容 |
| --- | --- | --- |
| `primary` | `brandPrimary` / `onBrandPrimary` | `primaryDisabled` / `onPrimaryDisabled` |
| `secondary` | `surfaceControl` / `textPrimary` | `secondaryDisabled` / `textDisabled` |
| `tonal` | `surfaceControl` / `brandPrimary` | `secondaryDisabled` / `primaryFaded` |
| `danger` | `destructive` / `onDestructive` | `destructiveDisabled` / `onDestructiveDisabled` |
| `text` | transparent / `brandPrimary` | transparent / `primaryFaded` |

`danger` 只用于不可逆操作的最终执行按钮。入口层的删除、不保存等动作使用 `secondary` 或 `tonal`。

```ts
type AppButtonProps = {
    label: string;
    variant?: "primary" | "secondary" | "tonal" | "danger" | "text";
    size?: "standard" | "compact";
    leading?: ReactNode;
    loading?: boolean;
    loadingLabel?: string;
    disabled?: boolean;
    onPress: () => void;
    className?: string; // 仅布局扩展
};
```

## 5. IconButton 与 BackButton

### 5.1 IconButton

- `standard` 为 48×48dp；`compact` 布局为 40×40dp，并通过 `hitSlop` 补足至少 44×44dp 触控区。
- 标准图标 24dp；密集型辅助操作可用 20dp。
- `ghost` 背景透明、内容 `textPrimary`；`tonal` 使用 `surfaceControl`；`selected` 使用 `surfaceSelected` 与 `brandPrimary`。
- 删除入口默认仍是中性色；只有最终危险执行入口才能使用危险色。

```ts
type IconButtonProps = {
    icon: ComponentType<IconProps>;
    accessibilityLabel: string;
    size?: "compact" | "standard";
    iconSize?: number; // 默认 24；密集辅助操作显式传 20
    variant?: "ghost" | "tonal" | "selected";
    selected?: boolean;
    loading?: boolean;
    disabled?: boolean;
    onPress: () => void;
    className?: string;
};
```

### 5.2 BackButton

- 默认复用 `IconButton compact`，Lucide `ArrowLeft` 为 24dp。
- 布局尺寸 40×40dp，触控范围至少 44×44dp，内容色使用 `textPrimary`。
- 可选文字模式下，图标与“返回”间距 8dp；文字 17sp。
- 组件只负责点击入口。Android 系统返回、先收键盘、关闭弹窗、保存草稿等优先级由业务层决定。

```ts
type BackButtonProps = Omit<IconButtonProps, "accessibilityLabel" | "icon" | "iconSize" | "selected" | "variant"> & {
    label?: string;
    accessibilityLabel?: string; // 默认使用 label；纯图标默认“返回”
};
```

## 6. Input 与 FormField

### 6.1 Input

- 单行高度 48dp；多行最小高度 96dp。
- 背景 `surfaceControl`，圆角使用 `radii.field`，当前 16dp。
- 默认保留 2dp 透明边框，聚焦或错误时只换颜色，不改变布局。
- 左右内边距 16dp；前后图标与文字间距 8dp；文字 17sp。
- 前后操作触控区不小于 44×44dp，密码显隐和清空按钮必须有可访问名称。

| 状态 | 背景 | 边框 | 内容 |
| --- | --- | --- | --- |
| 默认 | `surfaceControl` | transparent | `textPrimary` / placeholder `textSecondary` |
| 聚焦 | `surfaceControl` | `borderFocused` | `textPrimary` |
| 错误 | `surfaceControl` | `destructive` | `textPrimary` |
| 禁用 | `secondaryDisabled` | transparent | `textDisabled` |
| 只读 | `secondaryDisabled` | transparent | `textPrimary` |

```ts
type InputProps = Omit<TextInputProps, "className" | "editable" | "style"> & {
    invalid?: boolean;
    leading?: ReactNode;
    trailing?: ReactNode;
    clearable?: boolean;
    multiline?: boolean;
    readOnly?: boolean;
    disabled?: boolean;
    inputClassName?: string;
    containerClassName?: string;
};
```

实现使用 `forwardRef<TextInput, InputProps>`。`filled` 不额外改变外观，继续使用默认配方；状态优先级为 `disabled > readOnly > invalid > focused > default`。密码显隐通过受主题约束的 `Input.trailing + IconButton` 组合，字段本体不保存业务密码状态。

笔记正文编辑器具有双击唤起键盘、草稿和滚动测量协议，不强行替换为普通 `Input`；需要标题或名称显式保存行时使用 `InputSave`。

### 6.1.1 InputSave

- 由一个 `Input` 和一个保存入口组成，用于标题或名称的显式保存行；只承载视觉、交互锁定和无障碍，不持有业务保存、关闭或错误状态。
- 输入框与保存按钮均为 52dp 高，二者间距 8dp；输入框使用 `radii.field`、保存按钮使用 `radii.iconControl`，当前均为 16dp。
- 保存入口使用 `IconButton` tonal 配方的 `surfaceControl` 背景；Lucide `Save` 为 20dp，默认 `textSecondary` 灰色，禁用或保存中为 `textDisabled`。
- `saving` 时锁定输入和保存入口，并以原位指示器替换图标，不改变 52dp 尺寸；调用方必须提供 `onSave`，可覆写保存入口的无障碍名称。

```ts
type InputSaveProps = Omit<InputProps, "containerClassName" | "trailing"> & {
    onSave: () => void;
    saving?: boolean;
    saveAccessibilityLabel?: string;
    containerClassName?: string;
};
```

### 6.1.2 InlineHint

- 用于单行补充说明或轻量状态动作，不替代可关闭、跨页面的 `InlineMessage` / `Banner`，不接管加载、重试或业务状态机。
- 默认 `compact`：左侧 Lucide 图标 14dp、图文间距 6dp；`standard`：图标 20dp、图文间距 4dp，用于云同步等状态动作。文本均使用 `helper`、`numberOfLines={1}` 和尾部省略。
- `neutral` 的图标和文本使用 `textSecondary` 灰蓝；`important` 的图标和文本使用 `destructive` 红色；两者背景均为 transparent，不使用边框或圆角。
- 未传 `onPress` 时渲染静态容器，不产生点击、按压、无障碍按钮角色或触控热区；传入 `onPress` 时才渲染按钮角色的可点击容器。`disabled` 仅在可点击时阻止事件，状态色仍由业务 `tone` 决定；按压态为 85% 不透明度。
- 组件本体不带外边距；调用方仅可通过 `className` 设置布局间距，例如提示到按钮行 12dp。

```ts
type InlineHintProps = {
    icon: ComponentType<{ size?: number; color?: string }>;
    message: string;
    tone?: "neutral" | "important";
    size?: "compact" | "standard";
    onPress?: PressableProps["onPress"];
    disabled?: boolean;
    accessibilityLabel?: string;
    accessibilityState?: AccessibilityState;
    hitSlop?: Insets | number;
    className?: string;
};
```

### 6.2 FormField

- 标签 14sp、`textSecondary`；标签到输入框 8dp。
- 输入框到帮助或错误文字 6dp；相邻字段默认 16dp。
- 错误文字 14sp、`destructive`，使用 `accessibilityRole="alert"`。
- 密码显隐、验证码发送等作为 `Input.trailing` 提供，不复制输入框外壳。

```ts
type FormFieldProps = {
    label?: string;
    required?: boolean;
    helperText?: string;
    error?: string;
    children: ReactNode;
};
```

### 6.3 Expo SDK 56 控件选型

阶段 2 的基础组件使用 React Native 原语封装。SDK 56 的 `@expo/ui` Universal API 虽提供原生控件，但其输入控件使用独立 state/Host 组合；当前普通表单需要保持标准受控字符串、`TextInput` ref、键盘与自动填充属性，并严格复用现有主题配方，因此未在本批强行替换。后续 Picker、Switch、BottomSheet 等系统控件仍优先评估 `@expo/ui`。

## 7. IconPickerGrid 与 IconPickerDialog

### 7.1 IconPickerGrid

- 面板最大高度默认 240dp，按分组纵向滚动。
- 组间距 12dp；组标题 13sp、`textSecondary`；标题到图标 8dp。
- 图标格 48×48dp，间距 8dp，自动换行；圆角 `radii.iconCell`，当前 16dp，图标 24dp。

| 状态 | 背景 | 边框 | 图标 |
| --- | --- | --- | --- |
| 默认 | `surfaceControl` | transparent | `textSecondary` |
| 按压 | 默认配色，整体 pressed opacity | 同默认 | 同默认 |
| 选中 | `surfaceSelected` | 1dp `borderSelected` | `brandPrimary` |
| 禁用 | `secondaryDisabled` | transparent | `textDisabled` |

```ts
type IconPickerOption<T extends string> = {
    value: T;
    label: string;
    icon: ComponentType<IconProps>;
    disabled?: boolean;
};

type IconPickerGroup<T extends string> = {
    label: string;
    options: readonly IconPickerOption<T>[];
};

type IconPickerGridProps<T extends string> = {
    groups: readonly IconPickerGroup<T>[];
    value?: T;
    disabled?: boolean;
    maxHeight?: number; // 默认 240
    onChange: (value: T) => void;
};
```

分类模块只提供分类图标数据、当前值和保存行为；公共网格不得导入分类 Feature。

### 7.2 IconPickerDialog

- 使用 `AppDialog`：24dp 外边距、24dp 内边距、24dp 圆角、最大宽 440dp、最大高 85%。
- 标题到图标区 12dp；图标区到按钮 16dp。
- 取消在左、确定在右，等宽、高 48dp、间距 10dp。
- 选择过程只更新临时值；点击确定才提交。取消、遮罩和系统返回均放弃临时变化。

```ts
type IconPickerDialogProps<T extends string> = {
    visible: boolean;
    title: string;
    groups: readonly IconPickerGroup<T>[];
    value?: T;
    confirmLabel?: string;
    cancelLabel?: string;
    onConfirm: (value: T) => void;
    onClose: () => void;
};
```

## 8. AppDialog 与 DialogActions

### 8.1 AppDialog

- 必须通过现有 `AppModal` 承载，确保全局通知可以覆盖原生 Modal 层。
- 遮罩 `scrim`；外边距 24dp；卡片使用 `surface`、24dp 圆角和 24dp 内边距。
- 最大宽 440dp、最大高 85%；内容超高时由内容区域滚动，必要操作必须保持可达。
- 标题 24sp Regular，使用 `textPrimary`；标题行到内容 12dp。
- `busy` 时按业务要求阻止遮罩和系统返回，不能让异步操作静默中断。

```ts
type AppDialogProps = {
    visible: boolean;
    title: string;
    leading?: ReactNode;
    headerExtra?: ReactNode;
    children: ReactNode;
    dismissible?: boolean;
    busy?: boolean;
    onClose: () => void;
};
```

### 8.2 DialogActions

- 1 个按钮：通栏。
- 2 个按钮：同一行左右等分，间距 10dp；取消/次要操作在左，确认/主要操作在右。
- 3 个按钮：互斥对在第一行，第三个通栏按钮在第二行；行间距 10dp。
- 4 个及以上：纵向列表，每项通栏，间距 10dp。
- 操作归属有歧义时必须由产品确认，不允许组件猜测。

```ts
type DialogActionsProps = {
    layout?: "single" | "pair" | "pair-plus-single" | "stack";
    children: ReactNode;
    className?: string;
};
```

## 10. 调用方约束

```tsx
// 正确：业务只表达语义
<AppButton label="确定" variant="primary" onPress={submit} />
<Input invalid={!!error} />
<IconPickerGrid groups={groups} value={icon} onChange={setIcon} />

// 禁止：调用方重定义组件身份
<AppButton backgroundColor="#A855F7" />
<Input borderColor="green" />
```

- `className` / `style` 只允许布局扩展，例如 `flex-1`、宽度和外边距；不得覆盖背景、文字、边框、圆角或状态反馈。
- 所有图标按钮必须提供稳定的 `accessibilityLabel`；禁用、忙碌、选中状态必须同步到 `accessibilityState`。
- 组件内部必须使用原生 `disabled` 阻止点击，不能只改变颜色。
- 对组件身份确有新需求时，先增加语义 Token 和经过审阅的变体，再开放给页面。
