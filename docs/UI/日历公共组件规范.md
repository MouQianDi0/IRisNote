本组件实现后的以下场景必须先做真机布局实测，再下结论：截图判读、提出修改要求（附实测数据）、验证改动（导出控件树核对 dp 值）。实测步骤与判读规则同 [公共组件规范 §0](./公共组件规范.md)，无真机时跳过实测，不得编造数值。

## 1. 定位与使用场景

- 组件族：`AppCalendar`（周月双形态，含月份导航）与 `AppCalendarList`（多月纵向滚动，**契约保留、暂未实现**），落位 `src/shared/ui/Calendar/`，经 `src/shared/ui/index.ts` 导出。
- `AppCalendar` 双形态（v1.1 起）：**周视图**（收起态，单周条左右分页翻周）与**月视图**（展开态，导航翻月）；下滑展开、上滑收起。首个挂载点为待办页（第二页）容器上边框下 12dp。
- 用途：日期选择弹窗内的日历、按日期筛选笔记、待办页日期导航等纯日期选择场景。
- **不做**：agenda 模式、日程标注点、农历/节假日。出现需求时另行立项扩展，不得借机塞入。
- 组件只承载视觉、交互与无障碍；选中日期的业务含义（如筛选笔记列表）由调用方处理。

## 2. 数据契约：Date ID

- 组件内外一律使用 **Date ID**（`"YYYY-MM-DD"` 本地时区日期字符串），不使用 `Date` 对象穿越组件边界，从根上规避时区偏移。
- 提供并使用等价于 `toDateId(date)` / `fromDateId(id)` 的本地工具（可放 `src/shared/utils`）；**禁止** `new Date(id).toISOString().slice(0,10)` 式手工转换（UTC 偏移会错一天）。
- 月份 ID 复用当月 1 日的 Date ID（如 `"2026-09-01"`）。

### 3.1 周视图（收起态，v1.1 新增）

```text
│ 星期表头行（高 32dp，同上，含行底 1dp 分隔线）     │
│    一    二    三    四    五    六    日         │
│────────────────────────────────────────────────│
│    14   15  (16)  17   18   19   20             │  ← 单周行 48×48dp，与月视图同格同状态表
```

- 周视图总高 80dp = 表头 32 + 单周行 48；跨月日期**正常渲染**（否则翻周无意义），此为与 §4.3「非本月空白」的差异点（空白规则仅适用月视图网格）。
- 交互：**左右滑动分页翻周**（滚动窗口在边缘静默重建，近似无限）；**下滑展开月视图、上滑收起**（垂直位移 >14dp 且垂直分量占优时判定，高度动画 220ms）。
- 展开/收起锚定：展开取选中值所在月（无选中取当前周所在月）；收起取选中值所在周（无选中且当日在当前月取当日周，否则当前月首周）。
- 收起态无标题行与导航按钮。

## 4. 样式规格

### 4.1 月份标题行

- 月份标题 `"2026年9月"`：17sp（列表主文字档）· Regular · `textPrimary` · 居左，`numberOfLines={1}`。
- 右侧导航两枚按钮（ChevronLeft / ChevronRight，Lucide 20dp）：复用 `IconButton compact`（布局 40×40dp，hitSlop 补足 44×44dp 触控区），两按钮间距 4dp；`ghost` 变体、内容 `textPrimary`。
- 因 `calendarMinDateId` / `calendarMaxDateId` 到边界的月份：导航按钮原生 `disabled`，内容 `textDisabled`。
- `showMonthNav={false}` 或 `AppCalendarList` 中不渲染导航按钮，仅保留标题。

### 4.2 星期表头行

- 顺序默认周一起头（中文语境惯例）：`一二三四五六日`；`firstDayOfWeek="sunday"` 时为 `日一二三四五六`。
- 文字 13sp（脚注档）· Regular · `textSecondary`，每列水平居中；行高 32dp。
- 行底 1dp 分隔线，颜色 `divider`（#E0E0E0）。

### 4.3 日期格（核心状态表）

- 单元格 48×48dp；日期数字 17sp · Regular · 水平垂直居中。
- 选中/今日为**整格 48×48 矩形圆角**（`radii.control` 16dp · `borderCurve: "continuous"`，v1.1 取代 v1.0 的 40dp 圆）；范围色带贯穿整格宽度，端点仅外侧圆角、中段无圆角。
- 状态优先级：`disabled > selected > pressed > default`（实现注记：flash-calendar 的内部优先级为 selected > disabled，即范围内的禁用日仍显示选中态，属路线 B 已知取舍）。

| 状态 | 背景 | 数字颜色 | 形状 |
| --- | --- | --- | --- |
| 默认 | `transparent` | `textPrimary` | 无装饰 |
| 今天（未选中） | `surfaceSelected` | `brandPrimary` | 48dp 矩形圆角 16dp（v1.1：由仅蓝字升级为圆角矩形底） |
| 选中（单选值 / 范围端点） | `brandPrimary` | `onBrandPrimary` | 48dp 矩形圆角 16dp（端点仅外侧圆角） |
| 范围中间日 | `surfaceSelected` | `brandPrimary` | 全格色带（无圆角） |
| 按压 | — | — | 整体透明度 0.85，配色不变 |
| 禁用（min/max 外、disabledDateIds 内） | `transparent` | `textDisabled` | 无装饰，原生不可点击 |
| 非本月（月视图网格） | 不渲染数字 | — | 空白占位保持网格；周视图跨月日正常渲染 |

- `today` 与 `selected` 同日时按 `selected` 显示（选中优先）。
- 按压反馈统一透明度 0.85，禁用态不产生按压反馈；不引入缩放、涟漪等其他动效。

### 4.4 AppCalendarList 增量样式

- 月份标题行随内容滚动（**不吸顶**，v1 不做 sticky），标题规格同 §4.1；段间不加分隔。
- 滚动容器高度由调用方决定（弹窗内受 85% 最大高约束；页面内嵌由调用方给定）。

## 5. 功能契约

### 5.1 AppCalendar（单月）

```ts
type CalendarDateId = string; // "YYYY-MM-DD"，本地时区

type CalendarRange = { startDateId: CalendarDateId; endDateId: CalendarDateId };

type AppCalendarProps = {
    mode?: "single" | "range"; // 默认 "single"
    // 受控值：single 传 DateId | null；range 传 CalendarRange | null
    value?: CalendarDateId | CalendarRange | null;
    // 非受控初值（value 未传时生效）
    initialValue?: CalendarDateId | CalendarRange | null;
    onChange?: (value: CalendarDateId | CalendarRange | null) => void;
    initialMonthId?: CalendarDateId; // 初始显示月份，默认 value 所在月，再退到当月
    minDateId?: CalendarDateId; // 早于该日的日期禁用，且不可翻到更早月份
    maxDateId?: CalendarDateId; // 晚于该日的日期禁用，且不可翻到更晚月份
    disabledDateIds?: CalendarDateId[];
    firstDayOfWeek?: "monday" | "sunday"; // 默认 "monday"
    showMonthNav?: boolean; // 默认 true（仅月视图渲染）
    onVisibleMonthChange?: (monthId: CalendarDateId) => void;
    // v1.1 周月双形态
    viewMode?: "week" | "month"; // 受控视图形态
    initialViewMode?: "week" | "month"; // 初始形态，默认 "month"
    onViewModeChange?: (viewMode: "week" | "month") => void;
    className?: string; // 仅布局扩展（外边距、对齐），禁止覆盖颜色与圆角
};
```

### 5.2 AppCalendarList（多月）

```ts
type AppCalendarListProps = Omit<AppCalendarProps, "showMonthNav" | "initialMonthId"> & {
    initialMonthId?: CalendarDateId; // 保留：定位起始月
    estimatedMonthCount?: number; // 渲染窗口估计，默认前后各 24 个月
};

type AppCalendarListRef = {
    scrollToDate: (dateId: CalendarDateId, animated?: boolean) => void;
    scrollToMonth: (monthId: CalendarDateId, animated?: boolean) => void;
    scrollToToday: (animated?: boolean) => void;
};
```

`forwardRef` 暴露 `AppCalendarListRef`；`AppCalendarList` 无导航按钮，翻月靠滚动或命令式调用。

### 5.3 交互规则

| 模式 | 点击语义 |
| --- | --- |
| `single` | 点击可选日 → 成为选中值；再次点击已选中日 → **不取消**（日期选择必须有意义，取消交调用方 UI） |
| `range` | 第 1 次点击 → 设起点（临时终点=起点）；第 2 次点击 → 若晚于起点则设终点完成范围，若早于起点则**起点重设为该日**；第 3 次点击 → 放弃当前范围、以该日为新起点重新开始 |
| 禁用日 | 任何模式下点击无效果（原生 `disabled` 拦截） |

- `range` 模式下起点已选、终点未定时，后续点击实时重绘临时范围。
- 受控/非受控并存：传 `value` 即受控（`onChange` 只上报不落内部态）；都不传或仅传 `initialValue` 则内部持有。切不混用半受控。
- 翻月、命令式滚动触发 `onVisibleMonthChange`；组件不因翻月丢失已选值。

## 6. 无障碍

- 每个日期格：`accessibilityRole="button"`，`accessibilityLabel` 为完整日期（`"2026年9月14日"`，今天附加 `"，今天"`，选中附加 `"，已选中"`，范围端点附加 `"，范围起点/终点"`）；`accessibilityState.selected` / `.disabled` 同步真实状态。
- 导航按钮：`accessibilityLabel` = `"上一月"` / `"下一月"`；到边界禁用时同步 `.disabled`。
- 网格容器不劫持焦点顺序；读屏按行列顺序逐格播报，空白占位格不产生焦点节点。

## 7. 技术实现路线

> **实现定案（v1.1）：路线 B。** `@marceloterreiro/flash-calendar@2.0.0` + `@shopify/flash-list@2.0.2` 已安装；月视图网格由 flash-calendar `<Calendar>` 渲染、样式经 `CalendarTheme` 映射（`src/shared/ui/Calendar/flash-calendar-theme.ts`，模块级常量保证引用稳定）；周条复用 `Calendar.Item.Day` / `Calendar.Item.WeekName` 组合积木 + `buildCalendar` 周行元数据（跨月周直接取月矩阵对应行）。翻周为自管 ScrollView 分页滚动窗口（边缘静默重建）。已知取舍：① flash-calendar 无逐格无障碍标签注入点，日期格读屏播报受限（§6 部分让位）；② 范围内禁用日显示选中态（selected > disabled）；③ 表头行底 0dp 间隔以主题容器负 margin 抵消库内 4dp 统一间距，真机对账须验证。

两条路线，按需选择；**无论哪条，§3–§6 的视觉与契约不变**。

| | 路线 A：纯自绘（推荐 v1） | 路线 B：基于 flash-calendar |
| --- | --- | --- |
| 依赖 | **零新增**（View 网格 + Pressable） | 新增 `@marceloterreiro/flash-calendar` + `@shopify/flash-list >= 2.0.0` |
| 适用 | 单月 `AppCalendar`（35 格/屏，无虚拟化需求） | 多月 `AppCalendarList` 的无限滚动虚拟化 |
| Token 控制 | 完全受控，直接映射 `semanticColors` | 经 `CalendarTheme` 映射（见下表） |
| 风险 | 自实现月份计算（须测试跨月/闰年/周起点） | peer 依赖、上游样式自由度受 `CalendarTheme` 约束 |

**关键警示**：项目当前**未安装** `@shopify/flash-list`，而 flash-calendar v2.0.0 的 peerDependencies 硬性要求 `@shopify/flash-list >= 2.0.0`——走路线 B 必须同步引入 FlashList v2 并验证与 Expo SDK 57 / RN 0.86 的兼容性。

路线 B 的 theme 映射（`itemDay` 三态函数 → 本规范状态表）：

| `CalendarTheme` 字段 | 映射 |
| --- | --- |
| `rowMonth.content` | 17sp Regular `textPrimary` |
| `rowWeek.container` | 底部 1dp `divider` |
| `itemWeekName.content` | 13sp `textSecondary` |
| `itemDay.idle` | `textPrimary`；`isPressed` 时整体 0.85 |
| `itemDay.today` | `brandPrimary` 数字，容器透明 |
| `itemDay.active` | 端点圆 `brandPrimary`/`onBrandPrimary`，中间日 `surfaceSelected`/`brandPrimary`，`activeDayFiller` = `surfaceSelected` |
| 禁用 | `calendarMinDateId`/`calendarMaxDateId`/`calendarDisabledDateIds` 原生覆盖，数字 `textDisabled` |

日期格式化用 `Intl.DateTimeFormat("zh-CN", …)` 或项目自有工具实现，**不引入** date-fns/dayjs 等日期库；注意格式化函数必须保持引用稳定（组件外定义或 `useCallback`）。

## 8. 调用方约束

```tsx
// 正确：业务只表达语义与数据
<AppCalendar mode="range" value={range} onChange={setRange} minDateId="2026-01-01" />
<AppCalendarList ref={ref} value={date} onChange={setDate} />

// 禁止：调用方重定义组件身份
<AppCalendar selectedColor="#A855F7" dayRadius={8} />
```

- `className` 只允许布局扩展；颜色、圆角、字号一律走本规范，确有新需求先扩 Token / 变体再开放。
- 日历弹窗外壳（标题「选择日期」、确定/取消按钮）按视觉设计规范 §4 / §6 组装：`AppModal` 承载、`DialogButton` secondary/primary 等宽 48dp 间距 10dp；本组件只负责日历本体。

## 10. 实现勘误（v1.1 相对 v1.0 的裁定差异）

1. **选中/今日形状**：40dp 圆 → 整格 48×48 矩形圆角 16dp（`radii.control` 连续圆角）；今日由「仅蓝字」升级为 `surfaceSelected` 圆角矩形底 + 蓝字（用户裁定「参考设计规范做成矩形圆角」）。
2. **分隔线**：v1.0 ASCII 画了两条（标题行下 + 表头行下），v1.1 按用户裁定只保留表头行底一条；标题行到表头间隔 4dp。
3. **周历解禁**：v1.0「不做周历」作废，AppCalendar 增加周视图形态（§3.1）；周视图跨月日期正常渲染。
4. **AppCalendarList**：契约保留（§5.2），本轮不实现（无调用方无法验收）。
5. **落位文件**：`src/shared/ui/Calendar/`（`AppCalendar.tsx` / `WeekStrip.tsx` / `calendar-logic.ts` / `flash-calendar-theme.ts` / `index.ts`）+ `src/shared/utils/date-id.ts`；首个挂载点 `src/features/todos/screens/TodosScreen.tsx`（容器上边框下 12dp，`pt-3`）。
