# IRisNote 编辑器阶段 0 基线与回归清单

> 文档版本：0.1.0
> 建立时间：2026-08-07 02:36:24 +08:00
> 当前阶段：阶段 0（规范和基线冻结）
> 适用实现：纯文本编辑器基线

## 1. 基线目的

本文档固定块编辑器、草稿、版本历史和本地数据库引入前的真实行为。后续阶段必须使用相同输入复测，避免架构升级时静默改变创建、查看、编辑、保存、分享和统计结果。

本基线不代表阶段 1 之后的目标能力已经实现，也不把静态检查等同于真机验证。

## 2. 当前输入输出边界

| 场景 | 当前输入 | 当前成功结果 | 当前失败结果 |
| --- | --- | --- | --- |
| 创建笔记 | 非空标题、非空正文、可选分类 | `POST /notes` 后广播笔记变更并返回 | 系统提示框保留当前页面 |
| 查看笔记 | 正整数笔记 ID | 优先读取进程缓存，缺失时请求笔记列表 | 显示加载失败、重试或未找到状态 |
| 进入编辑 | 详情页顶部编辑按钮或列表长按菜单 | 跳转 `/pages/note/edit/[id]` | 非法或不存在 ID 显示状态页 |
| 编辑输入 | 标题和纯文本正文 | 只更新当前编辑器内存状态 | 当前没有自动落盘或异常恢复 |
| 保存编辑 | 非空标题，正文允许为空 | `PUT /notes/:id`，更新单条缓存并广播变更 | 显示错误；编辑页保持打开 |
| 分享 | 当前标题和字符串正文 | 生成复制内容或对应格式文件 | 显示生成或系统分享错误 |
| 字数统计 | 当前字符串正文 | 前端本地计算并使用本地缓存 | 不为统计单独请求服务端全文 |

## 3. 当前编辑链路

```text
NoteDetailScreen
└── NoteViewer
    └── NoteViewerHeader 编辑按钮
        └── /pages/note/edit/[id]
            └── EditNoteScreen
                ├── 进程缓存命中：直接读取 Note
                ├── 缓存缺失：GET /notes 后按 ID 查找
                └── NoteEditor（笔记适配层）
                    └── PlainTextEditor（core/editor）
                        ├── 临时标题和正文状态
                        ├── 返回
                        └── 提交原始输入
```

保存仍由 `NoteEditor` 执行标题校验、字符串裁剪、API 更新、缓存替换和事件广播。`core/editor` 不认识笔记 ID、分类、API 或缓存。

## 4. API 与服务端能力记录

当前前端仓库可以确认的接口：

| 方法 | 路径 | 当前用途 |
| --- | --- | --- |
| GET | `/notes` | 获取笔记列表并作为详情/编辑缺失缓存时的兜底 |
| POST | `/notes` | 创建标题、正文和可选分类 |
| PUT | `/notes/:id` | 更新标题、正文、分类、置顶或标星字段 |
| DELETE | `/notes/:id` | 删除笔记 |

当前前端契约没有 `revisionId`、`baseRevision`、草稿、条件更新、历史版本、块差异、同步游标或墓碑字段。服务端源码不在当前工作区，以上仅代表前端已观察到的能力，不能替代服务端审计。

## 5. 测试样本

测试样本位于 `tests/fixtures/editor/editor-fixtures.ts`：

- 空标题和空正文。
- 精确 30,000 字符长正文。
- Markdown 标题、列表和代码围栏。
- 本地与远程图片语法。
- 组合字符、Emoji、CRLF、零宽字符和替换字符。

长文本长度必须通过 `EDITOR_LONG_TEXT_TARGET_LENGTH` 与实际字符串长度共同校验，禁止只凭文件大小推断字符数。

## 6. 回归清单

### 6.1 创建

- [ ] 标题为空时阻止创建。
- [ ] 正文为空时阻止创建。
- [ ] 普通分类正确传递 `category_id`。
- [ ] “全部”分类不向服务端传虚拟分类 ID。
- [ ] 创建成功后列表能够刷新。

### 6.2 查看与进入编辑

- [ ] 缓存命中时直接显示笔记。
- [ ] 缓存缺失时可以通过列表请求找到笔记。
- [ ] 详情页顶部编辑按钮只压入一个编辑页面。
- [ ] 编辑页面只显示自定义顶部栏，不出现双 Header。
- [ ] 非法 ID 和不存在 ID 显示正确状态。

### 6.3 编辑与保存

- [ ] 初始标题和正文与查看页一致。
- [ ] 标题为空时阻止保存并保留输入。
- [ ] 正文允许保存为空字符串。
- [ ] 保存中按钮禁用并显示加载状态。
- [ ] 保存成功更新缓存、广播变更并返回。
- [ ] 保存失败保留编辑页面和当前输入。
- [ ] 快速返回不会误触发保存。

### 6.4 分享与统计

- [ ] TXT、Markdown、PDF、图片和复制入口保持原结果。
- [ ] 长内容图片分享仍执行既有长度保护。
- [ ] Markdown、代码、图片和链接统计语义保持不变。
- [ ] 字数统计不增加服务端正文请求。
