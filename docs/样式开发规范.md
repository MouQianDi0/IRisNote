# IRisNote 样式开发规范

本文档说明 IRisNote 在 Expo SDK 56、NativeWind v5 和 Tailwind CSS v4 下如何维护样式。

## 一、样式目录

```text
global.css                 NativeWind 语义令牌
src/theme/                 原生属性、SVG 和动画使用的 TypeScript 令牌
src/components/ui/         可复用的基础 UI 组件
src/app/                   页面独有的布局类名
```

## 二、以后应该在哪里修改

### 修改全局颜色或圆角

修改项目根目录的 `global.css`：

```css
@theme {
    --color-primary: #007aff;
    --radius-control: 12px;
}
```

使用这些令牌的组件会通过 `bg-primary`、`text-primary`、`border-primary`、`rounded-control` 自动更新。

如果同一颜色还用于图标的 `color`、SVG 的 `fill` 或动画对象，同时更新 `src/theme/colors.ts` 中同名的值。这些 API 不接收 NativeWind 类名。

### 修改所有同类组件

修改 `src/components/ui/`：

- `Button.tsx`：按钮背景变体。
- `TextField.tsx`：表单输入框基础样式。
- `Card.tsx`：通用卡片背景。
- `ModalPanel.tsx`：弹窗面板尺寸、圆角和阴影。
- `Screen.tsx`：页面根容器。

### 修改单个页面

只在对应页面的 `className` 中修改布局：

```tsx
<View className="flex-1 px-6 pt-8">
    <Text className="text-base text-gray-800">页面内容</Text>
</View>
```

不要为了一个页面独有的间距修改全局令牌。

## 三、新页面示例

```tsx
import { Button, Card, Screen, TextField } from "@/components/ui";
import { colors } from "@/theme";
import { Text } from "react-native";

export default function ExampleScreen() {
    return (
        <Screen className="bg-surface-muted px-6 py-5">
            <Card className="rounded-card p-5">
                <Text className="mb-4 text-lg font-bold text-gray-800">
                    新页面
                </Text>

                <TextField
                    className="mb-4 border-gray-200"
                    placeholder="请输入内容"
                    placeholderTextColor={colors.textMuted}
                />

                <Button className="rounded-control py-3">
                    <Text className="text-center font-semibold text-white">
                        保存
                    </Text>
                </Button>
            </Card>
        </Screen>
    );
}
```

## 四、什么时候使用 className

以下静态样式使用 NativeWind：

- Flex 布局与对齐。
- 固定间距和尺寸。
- 背景、文字、边框和圆角。
- 固定阴影和透明度。
- `active:`、`ios:`、`android:` 等状态或平台变体。

```tsx
<View className="flex-row items-center gap-3 rounded-card bg-white p-4" />
```

禁止在业务页面继续添加任意颜色：

```tsx
// 不推荐
<View className="bg-[#007AFF]" />

// 推荐
<View className="bg-primary" />
```

## 五、什么时候使用 style

以下情况保留 React Native `style`：

- `useAnimatedStyle` 返回的动画值。
- 根据运行时数据计算的颜色或尺寸。
- `contentContainerStyle` 等专用属性。
- SVG、图标和第三方组件只接收对象样式时。

```tsx
import { colors } from "@/theme";

<Icon color={colors.primary} />;
```

不要把固定背景、圆角或文字颜色重复写进 `style={{ ... }}`。

## 六、什么时候创建 styles 文件

NativeWind 页面通常不需要单独的样式文件。只有大量对象样式无法通过 `className` 表达时，才创建同目录文件：

```text
Feature.tsx
Feature.styles.ts
```

```ts
// Feature.styles.ts
import { colors } from "@/theme";
import { StyleSheet } from "react-native";

export const styles = StyleSheet.create({
    thirdPartyContent: {
        color: colors.textSecondary,
    },
});
```

不创建全项目共用的巨大 `styles.ts`。

## 七、动态类名规则

NativeWind 必须能在源码中看到完整类名：

```tsx
// 正确
const className = active ? "bg-primary" : "bg-gray-300";

// 错误：编译器无法可靠扫描动态片段
const className = `bg-${color}-500`;
```

新增状态时，在组件中写出每一个完整类名，或者为基础 UI 组件增加明确的 `variant`。

## 八、提交前检查

```powershell
npx tsc --noEmit
```

还应打开主要页面检查布局、文字换行、弹窗、禁用状态和动画。修改主题值时重点检查所有使用相同语义令牌的组件。
