# IRisNote 样式开发规范

本文档说明当前源码在 Expo SDK 56、NativeWind 5、Tailwind CSS 4 和 React Native Reanimated 4 下的样式组织方式。

## 1. 样式文件在哪里

```text
global.css                         NativeWind 静态语义 Token
src/shared/theme/colors.ts         图标、SVG 和动态对象颜色
src/shared/theme/radius.ts         数值圆角
src/shared/theme/spacing.ts        数值间距（已定义，当前较少使用）
src/shared/theme/typography.ts     数值排版（已定义，当前较少使用）
src/shared/theme/motion.ts         Reanimated 动效
src/shared/ui/                     跨业务基础 UI
src/features/*/screens/            页面布局
src/features/*/components/         业务组件样式
```

`src/app` 是路由层。业务页面样式应写在对应 Feature Screen 或组件中，不应重新放回路由文件。

## 2. 两套 Token 如何分工

### NativeWind Token

`global.css` 定义静态语义值：

```css
@theme {
    --color-primary: #007aff;
    --color-note-card: #e0eaff;
    --radius-control: 12px;
    --radius-card: 14px;
}
```

组件通过完整类名使用：

```tsx
<View className="rounded-card bg-note-card p-5" />
```

适用于：

- Flex 布局和对齐。
- 固定间距、尺寸和圆角。
- 静态背景、文字和边框颜色。
- 静态透明度和阴影。
- 平台或交互变体。

### TypeScript Theme Token

当 API 不接受 `className` 时使用 `src/shared/theme`：

```tsx
import { colors, radius } from "@/shared/theme";

<Icon color={colors.primary} />;
<Image style={{ borderRadius: radius.control }} />;
```

适用于：

- Lucide 图标的 `color`。
- SVG 的 `fill` 和 `stroke`。
- Reanimated 动态对象。
- 第三方组件的对象样式。
- 运行时计算值。

同一语义值同时存在于 `global.css` 与 `shared/theme` 时，修改必须同步。例如调整主色时应同时检查 `--color-primary` 和 `colors.primary`。

## 3. Shared UI

当前基础组件从统一入口导入：

```tsx
import { Button, Card, ModalPanel, Screen, TextField } from "@/shared/ui";
```

| 组件 | 文件 | 当前变体或职责 |
| --- | --- | --- |
| Button | `shared/ui/Button/Button.tsx` | `primary`、`disabled`、`secondary`、`danger` 外观变体 |
| Card | `shared/ui/Card/Card.tsx` | `surface`、`muted` |
| ModalPanel | `shared/ui/ModalPanel/ModalPanel.tsx` | `create`、`actions`、`confirm` |
| Screen | `shared/ui/Screen/Screen.tsx` | `plain`、`surface`、`centeredMuted` |
| TextField | `shared/ui/TextField/TextField.tsx` | 统一输入框基础外观 |

Shared UI 只负责通用外观和原生属性透传。登录、保存、删除分类等业务行为仍由 Feature 处理。

Button 的 `variant="disabled"` 只会应用灰色背景，不会自动禁止点击。实际禁用必须同时传递原生 `disabled` 属性：

```tsx
<Button variant="disabled" disabled>
    <Text>暂不可用</Text>
</Button>
```

## 4. 修改样式时找哪个文件

### 修改全局颜色或圆角

修改 `global.css`，并检查 `src/shared/theme` 中是否存在同语义值。

### 修改所有同类基础组件

修改 `src/shared/ui/<Component>/<Component>.tsx`。如果新增变体，需要同步扩展 Variant 类型和变体类名表。

### 修改单个业务页面

修改对应的 Feature：

```text
登录页面             features/auth/screens/LoginScreen.tsx
笔记列表             features/notes/screens/NotesScreen.tsx
笔记卡片             features/notes/components/card/NoteCard.tsx
分类栏               features/notes/categories/components/CategoryBar.tsx
用户中心             features/profile/screens/ProfileScreen.tsx
```

不要为了一个页面独有的间距修改全局 Token。

## 5. 新页面示例

```tsx
import { colors } from "@/shared/theme";
import { Button, Card, Screen, TextField } from "@/shared/ui";
import { Text } from "react-native";

export default function ExampleScreen() {
    return (
        <Screen className="bg-surface-muted px-6 py-5">
            <Card className="rounded-card p-5">
                <Text className="mb-4 text-lg font-bold text-gray-800">
                    新页面
                </Text>

                <TextField
                    className="mb-4 border-gray-200"
                    placeholder="请输入内容"
                    placeholderTextColor={colors.textMuted}
                />

                <Button className="rounded-control py-3">
                    <Text className="text-center font-semibold text-white">
                        保存
                    </Text>
                </Button>
            </Card>
        </Screen>
    );
}
```

## 6. `className` 与 `style` 的边界

优先使用 `className`：

```tsx
<View className="flex-row items-center gap-3 rounded-card bg-white p-4" />
```

以下情况使用 `style`：

- `useAnimatedStyle` 的返回值。
- 根据运行时数据计算的尺寸或颜色。
- `contentContainerStyle` 等专用属性。
- SVG、图标或第三方组件只接受对象样式。

```tsx
const animatedStyle = useAnimatedStyle(() => ({
    transform: [{ translateX: offset.value }],
}));

<Animated.View style={animatedStyle} />;
```

不要把固定背景、圆角和文字颜色重复写进对象样式。

## 7. 动态类名

NativeWind 需要在源码中看到完整类名：

```tsx
// 正确
const className = active ? "bg-primary" : "bg-gray-300";

// 不推荐：动态片段无法可靠扫描
const className = `bg-${color}-500`;
```

状态较多时使用明确映射：

```ts
const statusClassNames = {
    idle: "bg-gray-100 text-gray-600",
    active: "bg-primary text-white",
    danger: "bg-danger text-white",
} as const;
```

## 8. 动画

共享动画位于 `src/shared/theme/motion.ts`：

```tsx
import { pulse } from "@/shared/theme/motion";
```

当前包含：

- `buttonEasing`：长按缩放曲线。
- `pulse`：激活导航或分类图标的脉冲动画。
- `shake`：浮动主操作图标的周期摇动。

只服务于单一组件的动画可以留在组件内；多个业务或导航组件复用时再提升到 `motion.ts`。

## 9. 什么时候创建 `.styles.ts`

NativeWind 页面通常不需要单独样式文件。只有大量对象样式无法通过 `className` 表达时，才在组件旁创建：

```text
Feature.tsx
Feature.styles.ts
```

```ts
import { colors } from "@/shared/theme";
import { StyleSheet } from "react-native";

export const styles = StyleSheet.create({
    thirdPartyContent: {
        color: colors.textSecondary,
    },
});
```

不要创建全项目共享的巨大 `styles.ts`。

## 10. 修改后的检查

```powershell
npx tsc --noEmit
git diff --check
```

视觉检查至少覆盖：

- Light/Dark 系统主题下的可读性。
- 登录和注册表单的错误、禁用和提交状态。
- 笔记标题换行、卡片摘要和分类标签。
- 滑动操作层、分类创建/操作/删除弹窗。
- 头像缺失、上传中和上传后的缓存刷新。
- 不同屏幕宽度下的浮动菜单与安全区域。
